# CS-351 Project 2

This repository our group repository for Project 2 of CS-351. Each group member is added as a collaborator to this repository.

## Folders

* **frontend**: This is a React/Vite frontend application that is responsible for communicating with Express backend server. The application is compiled into a static files folder and the Express backend serves it.
* **backend**: This is a future Express application that manages user accounts, connection to the MongoDB backend database, etc.
